# La mia Giornata

Web app per attività, appuntamenti e orari sportivi (F1, MotoGP, Inter).

- App: https://andreaman003.github.io/giornata/
- `sport.json` viene aggiornato automaticamente ogni lunedì.
- I dati personali (attività, appuntamenti, foto) restano sul dispositivo e non sono in questo repository.
